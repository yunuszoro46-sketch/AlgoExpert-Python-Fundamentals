# 🐍 ProgrammingExpert — Python & Software Engineering Curriculum

Solutions, exercises, and software architecture implementations based on the official **[ProgrammingExpert](https://www.programmingexpert.io/)** curriculum by AlgoExpert.

---

## 🎯 About The Curriculum

**ProgrammingExpert** is an end-to-end software engineering program designed by former Big Tech engineers (Ex-Google, Ex-Facebook, Ex-Uber, Ex-Microsoft). It transitions learners from core computational thinking to industrial-grade software engineering, focusing heavily on Python, object-oriented design, systems engineering, and Go.

---

## 📚 Curriculum Structure

| Module | Core Topics & Focus Areas | Practice Sets |
| :--- | :--- | :---: |
| **1. Programming Fundamentals** | Control flow, data types, function scope, memory references, and algorithmic logic in Python. | **131 Questions** |
| **2. Object-Oriented Programming** | Classes, encapsulation, inheritance, polymorphism, dunder methods, and OOP design patterns. | **52 Questions** |
| **3. Advanced Programming** | Generators, decorators, closures, duck typing, context managers, and Python internals. | **49 Questions** |
| **4. Software Design** | Enterprise architecture, SOLID principles, scalable system patterns, and clean code paradigms. | Conceptual |
| **5. Software Engineering Tools** | Command line / Bash, Git version control, debugging environments, and development workflows. | **21 Questions** |
| **6. Programming with Go** | Statically typed systems programming, concurrency (goroutines/channels), and Go syntax. | **56 Questions** |

## 🛠 Featured Portfolio Projects

This repository contains full source code, test suites, and documentation for the 5 core capstone projects included in the program:

1. **Tournament Game Generator** — Command-line tournament management and seeding engine.
2. **Blackjack Card Game** — Object-oriented game loop utilizing core design patterns and state management.
3. **Asynchronous Point of Sale System** — Concurrent transaction processing and inventory tracking.
4. **Student Performance Tracker** — Analytical data parser and statistical performance calculation engine.
5. **Contact List App** — Persistent storage CRUD interface built with modular Python principles.
